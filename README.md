# מי מגיע? (MiMagi)

אפליקציית Android לניסוי בזיהוי מכשירי Bluetooth בסביבה, שמירת מכשיר בשם אישי וקבלת התרעה כשהוא מתגלה שוב.

## מה כלול בגרסה הראשונה
- סריקת BLE בזמן שהאפליקציה פתוחה.
- בחירת מכשיר שהתגלה ושמירתו בשם אישי.
- בחירת התרעה: מסך, קול או שניהם.
- מחיקת מכשירים שמורים.

## מגבלות חשובות
האפליקציה מזהה רק מכשירים שמשדרים פרסום Bluetooth Low Energy שניתן לסריקה. טלפון רגיל אינו בהכרח משדר כך, וכתובות Bluetooth עשויות להשתנות או להיות אקראיות. לכן אין הבטחה לזיהוי כל טלפון או לזיהוי אדם מסוים. עוצמת האות היא הערכה גסה בלבד ואינה מדידת מרחק.

בגרסה זו הסריקה פעילה בזמן שהאפליקציה פתוחה. סריקה אמינה ברקע דורשת שירות קדמי והתאמות נוספות למדיניות Android ולחיסכון בסוללה.

## Build
פתחו את לשונית Actions ובחרו את ה-workflow האחרון. לאחר הצלחה, הורידו את MiMagi-debug-apk.
